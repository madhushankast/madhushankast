## 🚀 Featured Projects

### 1. Multimodal Financial Fraud & Risk Detection System

An end-to-end fraud detection pipeline combining numerical features and categorical entity embeddings to identify potentially fraudulent financial transactions.

- Processed **590K+ transactions** from the IEEE-CIS dataset.
- Developed and benchmarked traditional ML models and hybrid PyTorch architectures.
- Achieved **0.4627 PR-AUC** with the hybrid model under chronological evaluation.
- Implemented cost-sensitive risk scoring, schema validation, and a Streamlit inference application.
- Added automated quality checks with **9/9 QA tests passing**.

**Tech:** Python, PyTorch, Scikit-learn, XGBoost, Pandas, Streamlit, SHAP

[View Project on GitHub](https://github.com/madhushankast)

### 2. Colombo Stock Exchange Market Intelligence Platform

A full-stack financial analytics and machine learning platform for market analysis, equity forecasting, and explainable predictions.

- Analyzed **5.5 years of daily OHLCV data** across 26 CSE equities.
- Engineered 58 technical, statistical, and market-dependency features per equity.
- Evaluated XGBoost, SARIMAX, and baseline models using walk-forward validation.
- Achieved **1.13% MAPE** with SARIMAX in the evaluated forecasting setup.
- Integrated SHAP explainability and Docker-based deployment.

**Tech:** Python, FastAPI, React, TypeScript, PostgreSQL, Pandas, Scikit-learn, XGBoost, SARIMAX, SHAP, Docker

[View Project on GitHub](https://github.com/madhushankast)

### 3. Regional Flood Risk Predictive Modeling & Ensemble System

An ensemble learning pipeline designed to improve predictive performance through model optimization, feature engineering, and stacking.

- Built an ensemble using CatBoost, LightGBM, and XGBoost on **20,886 samples with 59 features**.
- Implemented physics-based interaction features and out-of-fold target encoding.
- Optimized hyperparameters with Optuna and five-fold cross-validation.
- Reduced cross-validation error by **9.9%**, from 0.4312 to 0.3886, in the evaluated setup.

**Tech:** Python, CatBoost, LightGBM, XGBoost, Scikit-learn, Optuna, Ensemble Learning

[View Project on GitHub](https://github.com/madhushankast)

### 4. Market Basket Analysis & Customer Purchase Pattern Mining

A data mining project that discovers product associations and cross-selling opportunities from large-scale retail transactions.

- Processed **500K+ retail records** and constructed a sparse basket matrix.
- Implemented Apriori and FP-Growth association-rule mining.
- Identified 16 cross-sell rules satisfying the selected support, confidence, and lift thresholds.
- Found a maximum association-rule lift of **15.77x** in the evaluated dataset.

**Tech:** Python, Pandas, Mlxtend, Apriori, FP-Growth, Association Rule Mining

[View Project on GitHub](https://github.com/madhushankast)
